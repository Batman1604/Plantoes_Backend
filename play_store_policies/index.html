Políticas de Privacidade

Documento público do app de plantões

1. Termos de Uso

Ao utilizar o aplicativo Plantões, você concorda em usar a plataforma de forma legal, ética e responsável.

O usuário é responsável pelas informações inseridas, incluindo horários, valores e dados de plantões.

2. Política de Privacidade

Coletamos apenas os dados necessários para funcionamento do app, como nome, e-mail e dados operacionais dos plantões.

Os dados são tratados com confidencialidade e utilizados exclusivamente para entrega das funcionalidades do serviço.

3. Coleta e Uso de Dados

  • Dados de cadastro: identificação e autenticação da conta.
  • Dados dos plantões: organização da agenda e controle financeiro.
  • Dados de notificação: envio de lembretes e alertas do app.

Não comercializamos dados pessoais com terceiros.

4. Compartilhamento de Informações

Podemos compartilhar dados apenas quando necessário para cumprimento legal ou para operação técnica dos serviços (ex.: infraestrutura em nuvem).

5. Segurança

Adotamos medidas de segurança compatíveis com o mercado para proteger dados contra acesso não autorizado, alteração e perda.

6. Direitos do Usuário

Você pode solicitar atualização, correção ou exclusão dos seus dados por meio do canal de contato indicado abaixo.

7. Política para Crianças

O aplicativo não é direcionado para menores de 13 anos e não coleta intencionalmente dados de crianças.

8. Alterações nas Políticas

Estas políticas podem ser atualizadas periodicamente. Recomendamos revisão frequente desta página para acompanhar mudanças.

9. Contato

Em caso de dúvidas sobre políticas e privacidade, entre em contato pelo e-mail: suporte@plantoes.app.
